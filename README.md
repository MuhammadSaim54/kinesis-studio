## ✨ Features & Architecture

- **Obsidian Void Aesthetic**: Bespoke dark theme with radial volumetric glows, grain micro-noise overlay, and high-contrast typographic scales.
- **Dynamic Floating Island Navbar**: Blur-backed navigation capsule that collapses into an aerodynamic mobile drawer on screens below 768px.
- **Aerodynamic Kinetic Cursor**: GPU-accelerated custom cursor with magnetic hover detection and velocity-driven scaling.
- **Curated Works Archive (`#works`)**:
  - Filterable by Spatial Web, FinTech, and AI Systems.
  - Zero-lag vector telemetry artwork rendered with GPU transforms (`scale`, `translate`, `rotate`) — free from SVG attribute reflow errors.
  - Deep-dive inspection drawers with slide-over backdrop-filter choreography.
- **Capabilities Bento Matrix (`#services`)**:
  - Asymmetrical grid showcasing Raymarching Shaders, Edge Routing, Spring Physics, and Biometric WASM Ledgers.
- **Engineering Execution Matrix (`#methodology`)**:
  - Continuous hands-free auto-streaming protocol stepper with hover-pause functionality.
  - Bespoke hand-drawn arched vector highlight connecting headers directly to active pain points.
  - Live CLI telemetry emulator logging simulated real-time deployment passes.
- **Interactive Scope & Velocity Estimator (`#estimator`)**:
  - Real-time mathematical budget and sprint calculation engine.
  - Architectural archetype selectors, continuous interactive motion-tier track, and modular infrastructure toggles.
  - One-click cryptographic project specification export to system clipboard.
- **Obsidian Command Footer**:
  - Live dual world clocks (PKT / Asia/Karachi and UTC).
  - Encrypted quarterly dispatch submission box.
  - Mobile safe-area padding (`pb-28`) preventing bottom floating navbar collisions.
- **Full Viewport Elastic Scaling**: Deterministic visual balance across displays from 320px mobile screens up to 2560px+ ultrawide workstations.

- Node.js (v18.x or later)

```bash

# Navigate to project directory
